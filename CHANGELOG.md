# Changelog

All notable changes are documented here. Per-package changelogs are generated by [Changesets](https://github.com/changesets/changesets) in each package directory. This project follows [Semantic Versioning](https://semver.org).

## 0.1.0 — unreleased

First public version.

- `@uploadrescue/core`: content-based file detection, validation, failure classification (HTTP 413, provider size errors, network, timeout, custom), engine orchestration with output validation, bounded recovery state machine with cancellation and history.
- `@uploadrescue/react`: `<UploadRescue />`, `useUploadRescue`, `useUploadRecovery`, `useFileOptimization`; Strict Mode and SSR safe.
- `@uploadrescue/vanilla`: `createUploadRescue` with `attach`, drag and drop, events, widget.
- `@uploadrescue/ui`: shared view model, DOM renderer, accessible themable CSS.
- `@uploadrescue/upload-adapters`: fetch, XHR, multipart, S3 presigned, Supabase, Firebase, Cloudinary.
- Engines: image (worker-based, SVG sanitization), PDF, Office documents, ZIP, media (FFmpeg.wasm, opt-in).
